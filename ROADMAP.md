# Roadmap

The roadmap is driven by real task evaluations, not document volume.

## Foundation — current

- Establish the engineering constitution and minimal agent rules.
- Define the product-interface delivery loop.
- Treat wireframes as stateful screen contracts.
- Connect design-system decisions to implementation artifacts.
- Define synchronous and asynchronous backend interface guidance.
- Add schemas, a feature-slice template, a worked example, and CI validation.

## Cross-stack pilot

- Validate the workflow against TypeScript/Node.js, Python, and PHP projects.
- Add PostgreSQL, MySQL, Redis, and analytical-event storage profiles.
- Compare greenfield and legacy-maintenance tasks.
- Record repeated agent failure modes as evaluation cases before promoting new rules.

## Operational engineering

- Add infrastructure, deployment, observability, security, and recovery packs.
- Add project-map generation and drift checks.
- Add migration, rollback, incident, and maintenance templates.

## Evaluation and tooling

- Build repository-specific benchmark cases.
- Compare model-only, minimal-harness, skill-loaded, and full-workflow runs.
- Introduce a CLI only after the schemas and templates survive real project use.
